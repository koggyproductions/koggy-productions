# Koggy Productions LLP

> Indie Game Studio — Brother and sister duo (@v11ddx & @dhd.exe). Infinite curiosity. Independent game creators.

Official website and retro interactive arcade portal for **Koggy Productions LLP**.

Live Domain: [koggyproductions.org](https://koggyproductions.org)

## Features & Games
- **Koggy: Lovers Meet** — Grid-based puzzle adventure. Unite the two half-hearts while dodging dynamic snake hazards!
- **Koggy Aircraft** — Retro flight blaster featuring @v11ddx & @dhd.exe jets with 3-way arc spread blasters, altitude progression, and impassable barricade alerts.
- **Monster Boss** — Platform combat arena with bat swings, fireballs, and sonic dash mechanics.
- **Audio & Visuals** — Procedural Web Audio synthesizer, hot shower steam canvas, denim checker grid weave, interactive reactive typography, and duck stampedes.
